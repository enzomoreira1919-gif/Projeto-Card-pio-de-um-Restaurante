# Projeto-Card-pio-de-um-Restaurante
O sistema Cardápio de Restaurante tem como objetivo auxiliar no controle e organização dos pedidos realizados em um restaurante, permitindo cadastrar, acompanhar e gerenciar os pedidos das mesas de forma prática e eficiente. O sistema utiliza estruturas de dados como filas e pilhas para organizar o fluxo de preparo e entrega dos pedidos.
